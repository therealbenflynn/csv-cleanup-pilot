# Optional CSV cleanup pilot — $25

This is a small AI-assisted service experiment for one UTF-8 CSV file with **up to 100 data rows, 15 columns and 2 MB**, using explicitly agreed cleanup rules.

The proposed deliverable is a cleaned CSV, untouched source copy, a record of changes and unresolved exceptions. Possible operations include whitespace cleanup, agreed case normalization, unambiguous year-first dates and duplicate removal under an agreed rule. One correction to the agreed rules is included. Target delivery is two days after scope and a suitable private intake route are agreed.

No store access or automated import is included. Customer/order records, credentials and sensitive personal data are outside this pilot. Ambiguous business decisions, fuzzy matching, integrations and invented missing values are excluded.
